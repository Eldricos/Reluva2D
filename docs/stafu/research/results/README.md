# Diagnostic output archive

This directory is reserved for **sanitized, text-only** experiment results. It must not contain original game executables, sprite/image resources, bulk binary dumps, or large reconstructed instruction-byte sequences.

## Status
- M447 curated evidence is available in `m447-evidence.md`.
- Complete user-generated TXT outputs for earlier milestones have **not** yet been imported. Their absence is tracked in `../experiment-index.md`.
- The source-of-truth diagnostic scripts remain in `scripts/` on the development branch.

## Suggested metadata for future results
Milestone; script path and Git commit; original input filename/length/SHA256; output filename/SHA256; run date if known; verified observations; uncertainty; output archival status.

Do not label a summary as a full raw-output backup.
